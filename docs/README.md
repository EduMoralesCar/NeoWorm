## Propósito

Esta documentación está diseñada para:

- **Desarrolladores nuevos** — Entender la arquitectura y el código rápidamente
- **Contribuidores** — Conocer los estándares y procesos para aportar cambios
- **Mantenedores** — Tener una referencia clara de la estructura y decisiones técnicas
- **Stakeholders** — Visualizar el progreso y la calidad del proyecto mediante CMMI
